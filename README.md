# andaz-kumar-internship-assignment
Assignment for full stack development internship

This is the submission for the **Apollo 24|7 clone assignment**, which involved building a **Doctors Listing page** with filters and a backend API supporting **pagination**, **filtering**, and **image uploads** via `multipart/form-data`. The application is developed using the **MERN stack**, with **Cloudinary** used to store uploaded images and **MongoDB** as the database.

Although the assignment originally required **Next.js**, due to environment constraints I completed the frontend using **React (CRA)**. The **user interface may not be highly polished**, but I’ve prioritized building a solid **backend structure**, robust **data filtering**, and proper **API integration** with help of **redux-toolkit**, which all work as intended.
